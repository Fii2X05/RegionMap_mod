# Atlas-Map Mods

Minimap + fullscreen worldMap + Administrative region drawing for minecraft java 26.2 with fabric loader

|Keybinds|Action|
|--------|------|
|M       | Toggle minimap|
|+/-     | Zoom the minimap in or out|
|'       | Open the fullscreen map|
|B       | Open the waypoint list|
|N       | Open The region Manager|
-----------------------------------
